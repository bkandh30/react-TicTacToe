# React Tic Tac Toe Game

A classic Tic Tac Toe game built with React and styled using Tailwind CSS.

## Description

This is a web-based implementation of the classic Tic Tac Toe game where two players ('X' and 'O') take turns marking spaces in a 3x3 grid.

I created this project to learn React and Tailwind CSS.

## Technologies Used

- **React:** JavaScript library for building user interfaces.
- **Tailwind CSS:** Utility-first CSS framework for styling.
- **Node.js & npm:** For package management and running the development server.

## Getting Started

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/bkandh30/react-TicTacToe.git
    cd react-TicTacToe
    ```
2.  **Install dependencies:**
    Make sure you have Node.js and npm (or yarn) installed.
    ```bash
    cd react
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm start
    ```
    This will usually open the application in your default web browser at `http://localhost:5173`.
